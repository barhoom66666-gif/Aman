# الأمان — النموذج والحدود

## ما تحميه النسخة الحالية

| التهديد | الحماية |
|---|---|
| مشغّل الخادم يقرأ محتوى الرسائل | لا يملك مفاتيح خاصة، ولا يمكنه فك المغلفات |
| اعتراض الشبكة (بدون TLS) | المحتوى مشفّر من الطرف إلى الطرف |
| تسريب ملفات الوسائط من الخادم | بايتات مشفّرة فقط، المفتاح داخل رسالة مشفّرة |
| سرقة قاعدة البيانات | كلمات المرور scrypt، رموز الجلسات مجزّأة، لا نصوص صريحة |
| إعادة إرسال رسالة قديمة | AAD يربط الرسالة بمعرّفات المحادثة والمرسل والمستلم |
| عضو سابق في مجموعة يقرأ الجديد | تدوير المفتاح (epoch) عند تغيّر الأعضاء |

## ليس ضمن التهديدات المحمية حاليًا

1. **الخادم الخبيث النشط (MITM)**: لا توجد بعد آلية توقيع مفاتيح أو
   "أرقام أمان" يتحقق بها المستخدم هاتفيًا. الخادم يستطيع نظريًا استبدال
   مفتاح عام بمفتاح آخر عند أول تواصل.
2. **سرقة الجهاز غير المقفل**: الرسائل المخزّنة محليًا في SQLite غير مشفّرة
   (المفاتيح فقط في Keystore). استخدم قفل الشاشة وتشفير الجهاز.
3. **تحليل البيانات الوصفية**: من يتحدث مع من، ومتى، وأحجام الملفات —
   كلها ظاهرة للخادم.
4. **Forward Secrecy الكاملة**: المفتاح المؤقت لكل رسالة يمنع فك رسالة واحدة
   من كشف الأخرى، لكن تسريب مفتاح الهوية يفكّ الرسائل الموجّهة إليه
   (لا يوجد Double Ratchet).
5. **نسخ احتياطي/أجهزة متعددة**: لا يمكن استعادة محادثاتك على جهاز آخر.
6. **الإشعارات أثناء إغلاق التطبيق**: لا توجد خدمة Push في هذه النسخة.

## قائمة تقوية قبل الإنتاج

- [ ] HTTPS إلزامي (Caddy/Nginx) + إزالة `android:usesCleartextTraffic`.
- [ ] توقيع release بمفتاح خاص (`key.properties` + keystore).
- [ ] توقيع مفاتيح الهوية (Ed25519) والتحقق منها في العميل.
- [ ] أرقام أمان / QR للتحقق من الهوية بين المستخدمين.
- [ ] Double Ratchet كامل (مثل Signal) بدل ECDH لكل رسالة.
- [ ] تشفير قاعدة البيانات المحلية (SQLCipher) أو تشفير كل رسالة عند التخزين.
- [ ] تحديد معدّل أوسع، وتدقيق أمني خارجي، وسياسة خصوصية.
- [ ] نسخ احتياطي دوري لـ `data/` مع تشفير النسخة.
- [ ] حذف الرسائل من الخادم بعد تسليمها (اختياري) وسياسة احتفاظ.

## ملاحظات تشغيلية

- `data/aman.db` و`data/media/` هما كل ما يحتاجه النسخ الاحتياطي.
- رمز الجلسة يُخزَّن مجزّأ بـ SHA-256؛ إبطاله من `/api/auth/logout`.
- الحد الافتراضي للوسائط 25MB، وحد المغلف 96KB.
- الخادم يرفض الرسائل غير المشفّرة شكليًا (`bad_envelope`).

هذا مشروع تجريبي؛ لا تستخدمه لبيانات حساسة قبل إكمال قائمة التقوية أعلاه.
