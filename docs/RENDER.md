# تشغيل خادم Aman مجانًا على Render — من الهاتف فقط

هذه الطريقة لا تحتاج كمبيوترًا: الخادم يعمل في السحابة 24 ساعة، وتديره من متصفح
هاتفك. الملف `render.yaml` في المشروع يجعل الإعداد بنقرة واحدة.

> الخطة المجانية مناسبة للتجربة والاستخدام الخفيف. الخادم «ينام» بعد 15 دقيقة
> بدون استخدام، ويستيقظ تلقائيًا عند أول رسالة (30–60 ثانية). وقد تُمحى
> البيانات عند إعادة النشر. للاستخدام الجدي راجع قسم «للاستخدام الدائم» أسفل.

---

## 1) أنشئ حساب Render بحساب GitHub

1. افتح <https://dashboard.render.com/register> من متصفح هاتفك.
2. اختر **GitHub** وسجّل الدخول بحسابك نفسه (`barhoom66666-gif`).
3. وافق على ربط Render بمستودعاتك (يمكنك اختيار مستودع واحد فقط: `Aman`).

## 2) أنشئ الخادم

1. بعد الدخول افتح <https://dashboard.render.com/blueprints>.
2. اضغط **New Blueprint Instance**.
3. اختر مستودع **Aman** ثم **Connect**.
4. سيتعرّف تلقائيًا على `render.yaml` — اضغط **Apply / Deploy**.
5. انتظر 2–4 دقائق حتى تصبح الحالة **Live**.

## 3) انسخ عنوان الخادم

سيظهر أعلى صفحة الخدمة رابط مثل:

```
https://aman-server-xxxx.onrender.com
```

افتحه في المتصفح؛ يجب أن تظهر رسالة تشبه:

```json
{"ok":true,"service":"aman","time":...}
```

إن ظهرت، فالخادم يعمل ✅

## 4) اربط التطبيق بالخادم

1. افتح تطبيق **Aman** على هاتفك.
2. في شاشة الترحيب اضغط سطر **«الخادم: …»**.
3. الصق الرابط الذي نسخته (يبدأ بـ `https://`).
4. اضغط **حفظ**، ثم أنشئ حسابك.

> يمكنك تغيير العنوان لاحقًا من: الإعدادات ← الخادم.

## 5) تحديثات مستقبلية

كل `push` إلى `main` يعيد نشر الخادم تلقائيًا على Render (Auto-Deploy).
لإيقاف ذلك: Service → Settings → Auto-Deploy → No.

## للاستخدام الدائم (اختياري)

الخطة المجانية تفقد البيانات عند إعادة النشر وقد تنام عند الخمول. لجعلها دائمة:

1. Render → الخدمة → **Settings** → غيّر الخطة إلى **Starter** (7$/شهر).
2. أضف قرصًا: **Disks** → Add Disk:
   - Name: `aman-data`
   - Mount Path: `/data`
   - Size: 1 GB
3. أعد النشر.

أو استخدم أي خادم Linux/VPS لديك عبر Docker:

```bash
docker compose up -d
```

## حل المشكلات

| المشكلة | الحل |
|---|---|
| Build فشل | Render → Logs → أرسل لي آخر 20 سطرًا |
| `not found` عند فتح الرابط | انتظر حتى تصبح الحالة **Live** |
| التطبيق يقول «تعذّر الاتصال» | تأكد أن الرابط يبدأ بـ `https://` وأن `/health` يعمل |
| أول رسالة تتأخر دقيقة | الخادم كان نائمًا ويستيقظ الآن — طبيعي في الخطة المجانية |
| اختفت الرسائل بعد فترة | الخطة المجانية بلا تخزين دائم — راجع «للاستخدام الدائم» |
