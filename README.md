# Aman — مراسلة خاصة بلا مكالمات

تطبيق مراسلة أندرويد (وقابل للتحويل إلى iOS لاحقًا) مستوحى من فكرة JERNAS:
محادثات فردية وجماعية، صور وملفات، وتشفير من الطرف إلى الطرف — **بدون صوت أو فيديو**،
وبدون إعلانات أو تتبّع.

```
aman/
├── app/       تطبيق Flutter (أندرويد الآن، iOS لاحقًا بنفس الكود)
├── server/    خادم Node.js + WebSocket + SQLite
├── docs/      المعمارية وملاحظات الأمان
├── preview/   معاينة HTML تفاعلية للواجهة + صور الشاشات
└── .github/   بناء APK تلقائيًا عبر GitHub Actions
```

## معاينة الواجهة

قبل بناء APK يمكنك رؤية الشكل النهائي مباشرة:

- افتح `preview/index.html` في أي متصفح — تنقّل بين الشاشات، وجرّب الوضع الليلي.
- الصور الجاهزة في `preview/shots/` (محادثات، محادثة فردية، مجموعة، إعدادات، وضعان).

المعاينة نسخة ثابتة لمراجعة التصميم فقط؛ الوظائف الفعلية في كود Flutter.

## المزايا

- تسجيل حساب برقم الهاتف وكلمة مرور، ومفتاح هوية يُنشأ على الجهاز.
- العثور على الآخرين برقم الهاتف أو الاسم، أو بمسح باركود — دون الحاجة إلى جهات اتصال.
- صورة شخصية، جهات اتصال، شريط تنقل، وبحث/فلاتر/تثبيت للمحادثات.
- محادثات فردية مشفّرة بمخطط X25519 + HKDF-SHA256 + AES-256-GCM.
- مجموعات مع "جيل تشفير" (epoch) ومفتاح مجموعة يُوزَّع مشفّرًا لكل عضو على حدة، وتُنشأ بإضافة أي مستخدمين مسجّلين مباشرة.
- صور وملفات تُشفَّر على الجهاز قبل الرفع (الخادم لا يرى إلا بايتات مشفّرة).
- واجهة عربية RTL، وضع فاتح/داكن، مؤشرات كتابة، إشعارات قراءة، وحضور.
- تخزين محلي يعمل دون اتصال، وإعادة إرسال تلقائية للرسائل الفاشلة.

## التشغيل السريع

### 1) الخادم

```bash
cd server
npm install
npm start
# يعمل على http://0.0.0.0:8080
```

متغيرات البيئة الاختيارية: `PORT`, `DATA_DIR`, `DB_FILE`, `MEDIA_DIR`, `MAX_MEDIA_BYTES`.

اختبارات الخادم (تتحقق من التشفير والتسليم والمجموعات فعليًا):

```bash
cd server && npm test
```

### 2) التطبيق

يتطلب **Flutter 3.50 أو أحدث** (Dart 3.13+).

```bash
cd app
flutter pub get
flutter run
```

عنوان الخادم الافتراضي:
- محاكي أندرويد: `http://10.0.2.2:8080` (يشير إلى جهاز الكمبيوتر).
- جهاز حقيقي: من شاشة الترحيب اضغط «الخادم» وأدخل `http://IP-جهازك:8080`
  (نفس شبكة الواي فاي)، أو مرّر العنوان عند البناء:

```bash
flutter build apk --release --dart-define=AMAN_API=http://192.168.1.20:8080
```

الملف الناتج: `app/build/app/outputs/flutter-apk/app-release.apk`

### 3) بناء APK بدون جهاز تطوير

ارفع المشروع إلى GitHub ثم شغّل Workflow «Android CI» من تبويب Actions،
وسيُنزّل الـ APK كـ Artifact. يمكن ضبط عنوان الخادم من متغيّر المستودع `AMAN_API`.

الدليل الكامل خطوة بخطوة (إنشاء المستودع، الرفع، التشغيل، تنزيل APK، والتوقيع لاحقًا):
[`docs/GITHUB.md`](docs/GITHUB.md).

لتشغيل الخادم **بدون جهاز كمبيوتر** (استضافة مجانية تُدار من الهاتف):
[`docs/RENDER.md`](docs/RENDER.md).

## إضافة iOS لاحقًا

الكود نفسه يعمل على iOS؛ يلزم فقط توليد مجلد المنصة على جهاز Mac:

```bash
cd app
flutter create --platforms=ios --org app.aman --project-name aman .
cd ios && pod install
flutter run -d ios
```

ثم افتح `ios/Runner.xcworkspace` في Xcode لضبط Team/Bundle ID، وبعدها
`flutter build ipa` للنشر على App Store.

> لتجربة خادم HTTP محلي على iOS أثناء التطوير، أضف مؤقتًا
> `NSAppTransportSecurity → NSAllowsArbitraryLoads = true` في `Info.plist`،
> وأزلها قبل النشر (استخدم HTTPS).

> ملاحظة: لا تُشغّل `flutter create` على مجلد `android/` لأنه موجود ومهيأ بالفعل.

## الأمان — باختصار

| العنصر | الحالة |
|---|---|
| نص الرسالة | مشفّر على الجهاز، الخادم يخزّن مغلفًا فقط |
| الوسائط | مشفّرة قبل الرفع، والمفتاح داخل الرسالة المشفّرة |
| مفاتيح الهوية | في Android Keystore عبر `flutter_secure_storage` |
| كلمة المرور | scrypt مع salt على الخادم |
| البيانات الوصفية | غير مشفّرة (من يتحدث مع من، ومتى) |

حدود النسخة 0.1 موثّقة في [docs/SECURITY.md](docs/SECURITY.md): لا يوجد Double Ratchet
كامل، ولا تحقّق مفاتيح عبر أجهزة أخرى، والتوقيع يستخدم مفتاح debug.

**للإنتاج:** شغّل الخادم خلف HTTPS (Caddy/Nginx)، وأزل `usesCleartextTraffic`،
وأضف توقيع release حقيقي، وحدّد نسخًا احتياطية لقاعدة البيانات.

## النشر على خادم

```bash
docker compose up -d --build
```

ثم ضع Caddy أو Nginx أمام المنفذ 8080 لشهادة TLS. مثال Caddy:

```
chat.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

## استكشاف الأخطاء

- **«تعذّر الوصول إلى الخادم»**: تأكد أن الهاتف والكمبيوتر على نفس الشبكة، وأن المنفذ
  8080 غير محجوب بجدار الحماية، وأن العنوان صحيح.
- **«لم يُوزَّع مفتاح المجموعة بعد»**: انتظر لحظات؛ منشئ المجموعة يوزّع المفتاح تلقائيًا.
  إن استمرت المشكلة فافتح المجموعة من جهاز المنشئ.
- **رسالة «غير متاحة على هذا الجهاز»**: رسالة قديمة أرسلتها أنت من جهاز/تثبيت سابق
  (لا يحتفظ الخادم بالنص الصريح).
